# CLAUDE.md – ECL & ALCPT English Trainer (ecl-alcpt-trainer.com)

Permanent rules for every session.

## What this is
- Free ECL and ALCPT English practice: explained grammar, vocabulary, idiom and phrasal-verb questions, recorded
  listening questions, timed practice tests, lessons and topic pages. English first, with French (`fr/`) and
  Arabic (`ar/`) pages.
- Plain static HTML, no build step. GitHub Pages serves the `main` branch root (custom domain in `CNAME`,
  `.nojekyll`). Every push to `main` is live within minutes.
- `assets/site.css` is the shared stylesheet for the content pages. `practice/` is the web trainer
  (`practice/js/app.js`, question banks in `practice/data/`). `tg/` is the Telegram mini app, generated by
  `python3 tools/tg-miniapp/build.py`; never edit `tg/data.js` by hand.
- Workflows: `indexnow.yml` pings Bing/Yandex for changed HTML after each push; `listening-audio.yml` records
  listening audio with Kokoro TTS on GitHub's runners (free, no API key).

## Accuracy and trust
- All questions are original practice items. Never copy real ECL/ALCPT items or questions from other sites,
  apps or books. Never claim "real", "official" or "actual test" questions.
- Keep the disclaimer: not affiliated with DLIELC, the U.S. Department of Defense or any government. No seals,
  insignia or government-style design.
- `ads.txt` must keep the AdSense line exactly. `app-ads.txt` holds the same line so AdMob can verify the ECL app
  (com.ecltrainer.english) when its Google Play listing names this site as the developer website. Ads never sit
  inside a question, between a question and its answers, or next to answer buttons.

## SEO
- One `<h1>`, no skipped heading levels, title ≤ 60 characters, meta description ≤ 160, absolute self canonical,
  `hreflang` en/fr/ar/x-default on pages that have translations, BreadcrumbList on inner pages, no fake ratings.
- A new indexable page goes into `sitemap.xml`. A moved page keeps a redirect page at its old URL.
- `tg/` stays `noindex` (app shell).

## Performance and accessibility
- No framework. Images: WebP, explicit `width`/`height`, lazy below the fold; header/footer logo is
  `assets/img/logo-128.webp`. Keep PNG icons (favicon, apple-touch-icon) small with pngquant.
- WCAG AA contrast in light and dark themes (white text only on theme colours that pass 4.5:1; gold badges use
  navy text), visible focus, answers are real buttons, keyboard shortcuts keep working.

## Done means
- Every changed page opened and checked at 390 px and desktop, light and dark; no broken internal links;
  no console errors in `practice/`. Rebuild `tg/` if question banks changed.
